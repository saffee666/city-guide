# 架构

> TL;DR: Astro v7 + AstroWind（MIT）静态站，Tailwind v4；内容 = 4 个 JSON 集合驱动 4 个动态模板 + 十余个单页；图片位全部走「构建期 fs 检测，有图用图无图占位」。
> 产出：新增页型/模板能力时，本文记录其结构与约定。

- **Astro v7 + Tailwind v4**，底座模板 AstroWind（MIT，6042★）——剥掉了营销页，保留 Layout 体系

## 关键机制

- **BASE_URL**：所有站内链接用 `const B = import.meta.env.BASE_URL.replace(/\/$/, '');` 前缀——防止 `//` 协议相对 bug（曾致 /map 打不开）
- **图片位接口**：模板里 `fs.existsSync(path.join(process.cwd(), 'public', 'images', rel))` 构建期检测——文件存在→渲染 `<img>`/背景图，不存在→渐变/汉字色块占位。**丢图进 public/images/ 对应目录重新部署即生效**，不改代码
- **点亮地图**：china-ex-city（MIT）370 城构建产物 vendor 在 `site/public/map/`，首页 iframe 嵌入
- **导航**：`src/components/MegaNav.astro` 替换了 AstroWind Header（PageLayout 默认引用）——hover 全宽 mega：7 列大区 22 城 + 榜单/时令/路线/实务四组；移动端 .nav-links 隐藏（与源站一致）
